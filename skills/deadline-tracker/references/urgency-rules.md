# Urgency rules

| Days remaining | Level | Label |
|---|---|---|
| < 0 | 5 | OVERDUE |
| 0 | 4 | DUE TODAY |
| 1 | 3 | DUE TOMORROW |
| 2-3 | 2 | THIS WEEK (soon) |
| 4-7 | 1 | THIS WEEK |
| 8-14 | 0 | UPCOMING |

Adjustments:
- A deadline with a known **time earlier than 12:00** counts one level higher on its due day.
- Items the user marked as high priority, or from a priority sender, count one level higher (max level 5).
- Weekend dates: say the weekday explicitly ("Sat Nov 14") so the user can plan Friday.
